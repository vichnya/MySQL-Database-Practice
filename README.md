# MySQL Database Practice

Учебный проект на Python для работы с базой данных MySQL.

## Цель

На практике изучить подключение Python-приложения к MySQL, выполнение SQL-запросов и работу с данными из программы.

## Что реализовано

* подключение к MySQL;
* создание и работа с таблицей;
* выполнение SQL-запросов;
* добавление и получение данных;
* использование декоратора для организации подключения к базе данных.

## Технологии

* Python
* MySQL
* `mysql-connector-python`
* SQL

## Результат

Проект позволил на практике изучить взаимодействие Python-приложения с MySQL и выполнение SQL-запросов через `mysql-connector`.
